# Legacy Spreadsheet Functions

Tolaria no longer bundles IronCalc or evaluates spreadsheet formulas. This page is retained so old links resolve, but there is no current in-app function catalog or formula autocomplete.

For an existing sheet note, raw mode preserves the source until you edit it. Use an external spreadsheet application for formula evaluation, then keep a Markdown summary or link in Tolaria if the result belongs in the vault.
